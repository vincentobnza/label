# Label – Meet Some Friends 👥

**Label** is a modern social media platform built with React, TypeScript, and Vite. Our mission is to help users connect, share, and build genuine friendships in a simple, secure, and friendly environment.

This project is powered by a lightweight and high-performance Vite setup, perfect for modern web development with a seamless developer experience.

## 🛠 Tech Stack

- **React + TypeScript** – Modern UI development with static typing.
- **Vite** – Lightning-fast bundler with HMR for efficient development.
- **Tailwind CSS** – Utility-first styling for a responsive, clean design.
- **Supabase** – Backend as a service for authentication and real-time data.
